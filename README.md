# Stardust Burgers

Stardust Burgers is a responsive landing page for a fictional burger shop, designed to display menu items and provide basic contact functionality.

## Features

- Navbar for easy navigation.
- Menu sections for burgers, hotdogs, drinks, and more.
- Contact section with a demo form that does not send messages.
- Scroll animations and a moving space background with a play/pause control.
- Footer section at the bottom.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript, Bootstrap 5.3.8.
- **Animations:** AOS 2.3.4.
- **Fonts:** Audiowide and Orbitron via Google Fonts.
